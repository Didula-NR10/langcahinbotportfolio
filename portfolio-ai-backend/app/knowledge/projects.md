# Projects

These project summaries are transcribed from the portfolio's `src/data/projects.js`, which records public-repository checks and developer-supplied details. They describe the projects shown on the site; individual ownership is stated only where the portfolio specifies it.

## 1. TripSmart

An Expo travel client and FastAPI forecasting service for Sri Lankan districts, travel advisories, accounts, and saved notes. Technologies shown in the portfolio: TypeScript, React Native, Expo, Python, FastAPI, SQLAlchemy, Supabase, and Keras. The portfolio describes a hybrid layered and feature-based backend. Individual ownership of every feature has not been specified. Repository: https://github.com/Didula-NR10/TripSmart

## 2. Golden Treat Bakery

A PHP bakery application with customer and administrative areas, ordering, billing, stock, and account workflows. Technologies shown: PHP, HTML, CSS, JavaScript, MySQL, and Composer. Didula worked on PHP frontend/backend integration, login gating for cart actions, and admin FAQ management in this team project.

## 3. The Last Run

A Java Swing survival game with login, a player dashboard, stone collection, timed play, and a MySQL leaderboard. Technologies shown: Java, Swing, JDBC, MySQL, and Eclipse. Individual class ownership has not been specified.

## 4. Healthcare System

A Java Swing healthcare application. The developer's stated contribution is the database-connected Doctor Schedule Management module and its create, read, update, and delete operations. Technologies shown: Java, Swing, and database CRUD. Other team members' work is not attributed to the developer.

## 5. Rawana Ceylon

A React/Vite social client connected to a FastAPI backend for accounts, posts, stories, and profile workflows. Technologies shown: JavaScript, React, Vite, Python, FastAPI, PostgreSQL, Cloudinary, and Docker. Individual ownership of each feature has not been specified. Repository: https://github.com/Didula-NR10/socialmedia

## 6. NUMBERBOUND

A Godot/C++ 2D cooperative fantasy platform game featuring four characters, stacking, puzzles, number collection and crafting. The developer-supplied project document reports an implemented offline scope; multiplayer and later phases remain planned or unverified. Didula led architecture-first design and iterative C++/Godot development. The repository and release status have not been independently inspected.
